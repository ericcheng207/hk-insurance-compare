# 🏥 HK Insurance Compare

A clean, responsive static website for comparing Hong Kong's digital (virtual) insurance products. This site helps users discover and compare insurance offerings from Hong Kong's leading virtual insurers.

## 🌟 Features

- **Comprehensive Comparison**: Side-by-side comparison of 5 major virtual insurers in Hong Kong
- **Product Categories**: VHIS, Critical Illness, Life, Travel, Pet, Home, and specialty insurance
- **Fully Responsive**: Mobile-first design that works on all screen sizes
- **Interactive Filtering**: Filter products by category for easy comparison
- **Educational Content**: FAQ section explaining virtual insurers and their benefits
- **SEO Optimized**: Meta tags and semantic HTML for better search visibility

## 🏢 Featured Insurers

1. **Bowtie** - Market leader in VHIS and health insurance
2. **OneDegree** - Pet and home insurance pioneer
3. **Blue** - Comprehensive digital life insurance
4. **Avo Insurance** - Lifestyle and specialty insurance
5. **ZA Insure** - Basic digital health and life insurance

## 📄 Pages

- **index.html** - Landing page with hero section, quick stats, and insurer profiles
- **compare.html** - Interactive comparison table with filtering capabilities
- **about.html** - Educational content and FAQ about virtual insurers

## 🚀 Deployment

This site is designed for GitHub Pages deployment:

1. Push to your GitHub repository
2. Enable GitHub Pages in repository settings
3. Select the main branch as source
4. Your site will be available at `https://[username].github.io/hk-insurance-compare/`

## 🛠️ Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid and Flexbox
- **JavaScript** - Vanilla JS for interactivity
- **Google Fonts** - Inter font family for clean typography

## 📱 Responsive Design

- Mobile-first approach
- Breakpoints at 768px and 480px
- Hamburger menu for mobile navigation
- Flexible grid layouts
